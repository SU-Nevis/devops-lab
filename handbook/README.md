# Hands-on DevOps handbook

This is a road you drive, not a button you press. Type the commands, inspect the result, practise without a recipe, deliberately break it, repair it, and use a read-only grader to prove the state.

1. [`00-setup/`](00-setup/) — install and verify Docker Engine, GNU Make, `curl`, and Git.
2. [`01-docker/`](01-docker/) — run and inspect nginx by hand; prove ports, mounts, volumes, health checks, and networks.

The existing `make up`, `make verify`, and `make down` targets remain answer keys for the existing labs. They are not the learner path here.
