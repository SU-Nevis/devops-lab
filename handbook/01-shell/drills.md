# Linux and shell break/fix drill

Working directory: `handbook/01-shell`.

1. Run `sh ./check.sh` and confirm all 6 criteria pass.
2. Run `sh ./break.sh`. It plants exactly one fault and prints nothing about its cause.
3. Run `sh ./check.sh`; diagnose with `ls -l` and `stat`, without editing the grader.
4. Repair the artifact yourself.
5. Re-run `sh ./check.sh` until all 6 criteria pass.

Read `answers.md` only after you pass or after 15 minutes stuck.
